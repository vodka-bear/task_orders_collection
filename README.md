# Обработка заказов

Скрипт `index.php` читает список заказов из `orders.json`, считает показатели по оплаченным заказам и записывает сводку в `output.json`.

Нужен PHP 8.2 или новее. Запуск из каталога проекта:

```bash
php index.php
```

## Как устроена обработка

Скрипт читает `orders.json` и разбирает его в коллекцию заказов. Каждый заказ — объект с номером, именем покупателя, суммой и статусом.

Дальше по коллекции считаются такие показатели:

1. Полный список заказов.
2. Заказы со статусом `paid`.
3. Количество оплаченных заказов.
4. Общая сумма оплаченных заказов.
5. Самый дорогой оплаченный заказ. При равных суммах остаётся тот, который встретился раньше.
6. Заказы с суммой не менее 2000.
7. Группы по статусам: заказы группы и их количество.

Отчёт печатается в консоль. Та же сводка сохраняется в `output.json`.

## Входные данные

Корень `orders.json` — массив объектов. У заказа четыре поля:

| Поле | Значение |
| --- | --- |
| `id` | целое число больше нуля |
| `customer` | непустая строка |
| `amount` | число не меньше нуля |
| `status` | `paid` или `pending` |

## Результат для исходного списка

```text
Количество оплаченных заказов: 3
Общая сумма оплаченных заказов: 4500
Самый дорогой оплаченный заказ: № 103 на сумму 3000
```

Если оплаченных заказов нет, скрипт печатает `Оплаченных заказов нет`.

`output.json` содержит количество и сумму оплаченных заказов, самый дорогой оплаченный заказ, заказы от 2000 и группы по статусам.

## Проверка данных

При некорректных данных обработка останавливается до печати отчёта и до записи `output.json`. Сообщение выводится в stderr, код выхода — 1.

| Ситуация | Сообщение |
| --- | --- |
| JSON не удалось разобрать | `JSON не удалось декодировать` |
| В корне JSON не массив заказов | `JSON должен содержать список заказов` |
| Элемент списка не является заказом | `Заказ с индексом N имеет некорректный формат` |
| Нет обязательного поля | `У заказа отсутствует обязательное поле: {поле}` |
| Некорректный номер заказа | `Идентификатор заказа должен быть положительным целым числом` |
| Некорректное имя покупателя | `Имя покупателя отсутствует или имеет некорректный тип` |
| Сумма нечисловая | `Сумма заказа имеет некорректный тип` |
| Сумма меньше нуля | `Сумма заказа отрицательная` |
| Неизвестный статус | `Статус заказа неизвестен` |
| Файл `orders.json` недоступен | `JSON файл не найден или недоступен для чтения` |
| Не удалось записать результат | `Не удалось создать файл` |

## Файлы

- `index.php` — чтение, расчёт и вывод
- `orders.json` — исходный список заказов
- `output.json` — сводка последнего запуска
